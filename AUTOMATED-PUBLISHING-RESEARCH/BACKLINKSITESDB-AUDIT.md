# BacklinkSitesDB-auditointi

**Tarkistettu 3.11.2026.** Palvelu: [backlinksitesdb.com](https://backlinksitesdb.com/).

## Julkisen näkymän tulos

Sivusto mainostaa yli 400 korkean DR:n backlink-/hakemistokohdetta ja maksullista manuaalista submit-palvelua. Tarkistettu julkinen listanäkymä näytti suodatuksen jälkeen “No directories found matching your criteria” ja 0/0 tulosta. Yhtään tietuetta ei voitu poimia, deduplikoida tai tarkistaa.

Tämä ei todista, ettei palvelussa olisi muuta aineistoa; se osoittaa vain, ettei avoin näkymä tarjonnut tässä tarkistuksessa arvioitavaa listaa. Kirjautumista, maksua, CAPTCHAa tai teknisten suojausten kiertämistä ei tehty.

## Selvitystaulukko

| Kysymys | Havainto |
|---|---|
| Koko tietokanta julkinen? | Ei vahvistettu; näkyvä lista oli 0/0. |
| API tai vienti? | Julkista dokumentoitua APIa/CSV-vientiä ei varmennettu. |
| Kategoriat/suodattimet? | UI:ssa näkyy suodattimia, mutta tyhjä taulukko estää niiden sisällön arvioinnin. |
| Maksullinen vai ilmainen? | Maksullista manuaalista palvelua mainostetaan; kohdekohtaisia submit-ehtoja ei saatu. |
| Dofollow/nofollow/UGC? | Ei kohdekohtaista näyttöä. DR-väite ei osoita rel-arvoa. |
| Klikattavuus/julkisuus? | Ei voitu tarkistaa ilman tietueita. |
| Tilit, vastalinkki, hyväksyntä? | Ei tarkistettavaa tietuetta. |
| Päivitys- ja varmennuspäivä? | Kohdekohtaista ylläpitoa tai tarkastusmenetelmää ei varmennettu. |
| Aktiiviset ja hyväksyvät sivustot? | Ei voitu tarkistaa. |
| Matkailu/Espanja/Suomi-relevanssi? | Ei yhtään vahvistettua ehdokasta. |
| Heikkolaatuiset/vanhentuneet kohteet? | Ei arvioitavissa; avoin riski, ei todettu vika. |

## Tulos ja jatko

Vahvistettuja julkaisumahdollisuuksia: **0**. Maksullisen paketin laatua, liikennettä, linkkiattribuutteja, hyväksyntää tai pysyvyyttä ei voitu arvioida; sitä ei suositella tämän näytön perusteella.

Jos yksittäinen listaus myöhemmin löytyy, tarkista sen aktiivisuus, matkailuyleisö, todellinen julkaisupaikka, href/rel, kirjautumis- ja maksuvaatimukset, vastalinkki, toimituksellinen laatu, näkyvyys, crawlattavuus ja tarkistuspäivä. Hakemistoa käytetään vain jos talvehtija hyötyy siitä. Ei massalomakkeita.

Google edellyttää kaupallisten linkkien asianmukaista luokittelua, eikä linkin saaminen yksin takaa ranking-hyötyä. [Link qualification](https://developers.google.com/search/docs/crawling-indexing/qualify-outbound-links), [spam policies](https://developers.google.com/search/docs/essentials/spam-policies).
